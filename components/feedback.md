# Feedback and state surfaces

## Status stamps

Status stamps are square written labels.

Healthy, warning, unavailable, waiting, blocked, and selected states must have written labels.

Color reinforces the label and does not replace it.

## Toast and inline feedback

Use inline feedback when the message belongs to a specific field or operation.

Use a toast only for short-lived feedback that does not require a decision.

Important failure copy must remain visible until the user can understand or dismiss it.

## Empty, loading, and error states

Empty states explain what is absent and what the user can do next.

Loading states explain what is being checked when the wait is meaningful.

Unavailable states distinguish unavailable data from an empty result.

Error states name the failed operation and provide a recovery action when possible.

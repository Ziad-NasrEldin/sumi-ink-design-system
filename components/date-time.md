# Date and time controls

## Purpose

Date and time controls collect a bounded temporal value.

Use the platform-native date and time control when its behavior improves accuracy and remains visually acceptable.

Use the Sumi-Ink field and dropdown contracts when the platform control would create an inconsistent branded surface.

## Contract

Date and time values must include a visible label and an understandable format.

Invalid ranges must be explained in written language.

Time zone behavior must be explicit when it changes the meaning of the value.

Arabic interfaces must use localized date order and logical direction.

The control must remain usable with keyboard, VoiceOver, large text, and reduced motion.

# Navigation and command index

## App shell

The app shell establishes the workspace, command index, and current destination.

The current destination uses written selected state, ink inversion, or a seal marker.

Navigation labels use the operational label style.

## Command index

The command index keeps primary routes discoverable.

On compact layouts it collapses into an explicitly labeled menu trigger.

The trigger must not rely on an icon without a written accessible label.

## Tabs

Tabs switch between related views without changing the task context.

The active tab uses ink or seal treatment plus an accessible selected state.

Tabs must remain keyboard navigable.

## Icons

Use line icons at `14px` to `18px`.

Icons reinforce written labels rather than replacing them for critical actions.

Directional icons mirror in RTL when their meaning is directional.

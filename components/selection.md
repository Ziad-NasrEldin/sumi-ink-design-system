# Selection controls

## Segmented controls

Segmented controls are for a small set of mutually exclusive views or modes.

The selected segment uses ink fill with paper text.

The control uses square segments and a one-pixel rule.

The selected state must also be exposed to assistive technology.

## Toggles and checks

Toggles represent an immediate on or off setting.

Checkboxes represent an independently selectable item or a multi-select choice.

The control must expose its current value in written accessible language.

State-changing selection controls provide immediate visible feedback.

Destructive changes require confirmation when the change is not easily reversible.

# Text fields

## Purpose

Text fields collect or edit a bounded value.

Use labels that remain visible when the field has a value or an error.

## Contract

Fields use Sumi Paper background, a one-pixel strong rule, and zero radius.

Focus uses an ink border and a visible Sumi Seal marker.

Errors use Danger Field background, Seal Deep text, and written corrective copy.

Disabled fields use Mist background and Muted text.

Placeholder text is supplementary and must not replace a label.

The field must preserve a usable target size on touch devices.

## Validation

Validation copy explains what is wrong and how to correct it.

Validation must not appear only through color.

Async validation must distinguish checking, accepted, rejected, and unavailable states.

Arabic validation must use translated message content and preserve logical field order.
